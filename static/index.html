Маршруты квантового эмулятора

python interfaces/phi_compiler_cli.py \
  --mode quantum-method-scan \
  --max-order 5 \
  --limit 40 \
  --output reports/quantum_method_scan_cli_v3_1.json

python interfaces/phi_compiler_cli.py \
  --mode quantum-method-query \
  --capability environment_memory \
  --limit 10 \
  --output reports/quantum_method_query.json

Маршрут метода не является законом и не доказывает достижимость 512 кубитов. Стоимость определяется структурой запутанности, treewidth, magic и бюджетом ошибки.
