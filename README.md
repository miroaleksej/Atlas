## Главный архитектурный принцип

Atlas разделяет четыре объекта:

1. **Observation** — данные и provenance.
2. **Representation** — текущие оси, тип пространства и математический язык.
3. **Hypothesis** — проверяемая конструкция, не закон.
4. **Claim** — текстовое утверждение с обязательным происхождением.

Гипотеза проходит состояния:

```text
IDEA → CANDIDATE → TESTABLE → SURVIVOR → LAW-CANDIDATE → PROMOTED OWNER
```

`SURVIVOR` не равен `LAW`. Scientific promotion остаётся отдельным владельцем.

## Hypothesis synthesis без знания закона

`ADAPTIVE-HYPOTHESIS-SYNTHESIS/15.2.8` исследует по одному complexity shell за цикл. Глобального fixed polynomial/order ceiling нет. Следующий цикл может открыть следующий shell.

Вместо заранее заданного списка «правильных формул» используется typed fair-dovetail construction. Для монома

```math
m(x)=\prod_i x_i^{p_i}
```

и target-размерности `D_y` коэффициент получает размерность автоматически:

```math
D_{c_m}=D_y-\sum_i p_iD_{x_i}.
```

Это позволяет системе исследовать необычные связи, не нарушая типовую корректность.
