# Наблюдения NASA Exoplanet Archive

`PSCompPars_2026.09.20_07.33.39.csv` — предоставленный пользователем снимок: 6366 строк, 84 столбца. Исходные байты, комментарии, единицы измерения и пропуски сохранены. SHA-256 и происхождение записаны в `PROVENANCE.json`.

Это тот же снимок, который использован в отчёте Deep Research patch, а не новые независимые данные. Каталог `PSCompPars` композитный: значения могут происходить из разных публикаций и включать производные оценки. Восстановление известной размерностной зависимости на нём не является открытием нового закона.

Для анализа остатка отбирается одна целая строка планеты на звезду по минимальному SHA-256 имени планеты. Значения других планет не используются для заполнения пропусков. Затем исключаются строки, в которых требуемые преобразованные координаты не конечны. Группы discovery/validation/sealed задаются хешем имени звезды, поэтому планеты одной звезды не попадают в разные группы.

Из корня репозитория:

```bash
python -m pip install -e '.[exoplanet]'
python -m evaluation.exoplanet_nasa2026_blind_experiment \
  data/observations/nasa_exoplanet/PSCompPars_2026.09.20_07.33.39.csv \
  --out /tmp/atlas-exoplanet-replay.json
```

Для обычного повторного запуска результат следует сохранять вне запечатанного дерева. Отчёт выполненного при интеграции запуска находится в `reports/exoplanet/NASA_EXOPLANET_2026_LOCAL_RUN.json`. Исходный отчёт автора патча сохранён отдельно, без подмены его результатов.
